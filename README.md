# Ancre

Application web personnelle d'apprentissage : petites cartes interactives, révision espacée, tri des erreurs. Un seul utilisateur.

- **Utiliser l'app** : [UTILISATION.md](UTILISATION.md) (session quotidienne, ajouter une matière, installer, mettre en ligne).
- **Écrire une matière** : [SCHEMA.md](SCHEMA.md) (format JSON, exemple complet).
- **Développer** : [CLAUDE.md](CLAUDE.md) (stack, conventions, règles produit, avancement).
- **Pourquoi c'est construit comme ça** : `docs/plan_app_apprentissage.md` (produit) et `docs/plan_app_partie2_ui.md` (design).

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # tests de l'algorithme de révision
```
